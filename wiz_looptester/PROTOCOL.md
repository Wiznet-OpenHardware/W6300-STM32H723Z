# WIZ LoopTester — 통신 프로토콜 계약서 (v2, 단방향 측정)

> PC = **TCP 서버(listen)** / 장비(WIZ630MJ) = **클라이언트(connect)**  ← 역할 반대 아님
> 대역폭은 **단방향**으로 측정 (에코·왕복 없음). 무결성은 **약속된 패턴**으로 검사.

---

## 0. 환경 / 접속

| 항목 | 값 |
|------|-----|
| PC 서버 IP : Port | **192.168.11.42 : 5000** (PC 인바운드 5000 방화벽 허용) |
| 장비(출발지) IP | 192.168.11.99 |
| 한 세션 | 장비가 **4번 순차 접속** (동시 ❌, 하나 끝나면 다음) — 서버는 accept 루프 |

세션 4연결 순서(장비가 헤더로 선언, **PC는 순서 가정 없이 헤더로 분기**):
`①[QSPI][TX]  →  ②[QSPI][RX]  →  ③[BUS][TX]  →  ④[BUS][RX]`

4개가 모이면 PC가 **전체 PASS/FAIL** 을 표시. 다음 DUT는 "결과 초기화(NEW DUT)" 버튼.

## 1. 약속된 패턴 (양측 공통)

데이터 페이로드는 ASCII 숫자가 0부터 순환하는 고정 패턴:

```
byte[i] = '0' + (i % 10)
→  "0123456789012345678..."   (오프셋 0부터 정렬)
```

- 송신측은 페이로드 첫 바이트를 **오프셋 0('0')부터** 시작해 끊김 없이 이어서 전송.
- 수신측은 받은 바이트가 자신의 누적 오프셋 기준 패턴과 일치하는지 검사.
- 한 바이트라도 불일치 → **손상 불량**.

---

## 2. 한 연결 = 한 측정 (방향은 헤더가 선언)

장비가 접속하면 **헤더 한 줄**을 먼저 보낸다 (`\n` 또는 `\r\n` 종료):

| 헤더 | 의미 |
|------|------|
| `[QSPI][TX]` | 장비 → PC 송신 (TX throughput). PC는 받기만 함 |
| `[QSPI][RX]` | PC → 장비 송신 (RX throughput). 장비가 받아서 측정 |
| `[BUS][TX]` / `[BUS][RX]` | BUS 인터페이스 |
| `[QSPI]` (방향 생략) | `[QSPI][TX]` 로 간주 (기본 TX) |

대소문자 무관. 인터페이스/방향 둘 다 양방향 검증하려면 장비가 **연결을 나눠서**
(`[QSPI][TX]` 연결 → close → `[QSPI][RX]` 연결 → close …) 순차로 수행.

---

## 3. TX 측정 (장비 → PC)

```
장비: 접속 → "[QSPI][TX]\r\n" → 패턴을 N초간 끊김없이 송신 → close
PC  : 헤더 파싱 → 첫 데이터 바이트에서 타이머 시작
      → close(EOF)까지 recv 바이트 합산 + 패턴 무결성 검사
      → Mbps = 받은바이트 * 8 / 경과초 / 1e6
```

- N(송신 시간)은 **장비가 결정**. PC는 EOF로 종료를 인지.
- PC는 **에코/회신 없음**. 받기만 함.

---

## 4. RX 측정 (PC → 장비)

```
장비: 접속 → "[QSPI][RX]\r\n" → 이후 수신만, 바이트/오류 집계
PC  : 헤더 파싱 → 패턴을 M초간 송신(M = 화면의 RX Duration)
      → 송신 끝나면 shutdown(SHUT_WR)  (= 데이터 끝 신호, EOF)
장비: recv가 EOF 반환 → 집계 종료 → 결과 1줄 회신 → close
      "[RESULT]bytes=<수신바이트>,ms=<경과ms>,err=<불일치바이트수>\r\n"
PC  : 결과 파싱 → Mbps = bytes * 8 / (ms/1000) / 1e6
```

- 장비가 `[RESULT]` 를 못 주면 PC는 **자체 송신율로 근사**(TCP 버퍼링 때문에 부정확)하고
  무결성은 "미확인"으로 표기.

---

## 5. 합격 판정

| 조건 | 판정 |
|------|------|
| `Mbps ≥ Min Mbps` 그리고 `err == 0` | **정상** |
| 위 조건 불충족 | **불량** |
| `err` 미확인(RESULT 없음) | 속도만으로 판정 + "무결성 미확인" 표기 |

---

## 6. 비고
- 종료문자: 헤더/결과 줄은 `\r\n` 또는 `\n`. 대량 데이터 구간은 줄 구분 없음(원시 바이트).
- 측정 구간에는 데이터 검증을 위해 마커(`[` 포함)를 데이터에 섞지 않는다 (패턴은 숫자뿐).
- PC 수신 버퍼는 크게(`SO_RCVBUF`), `TCP_NODELAY` 설정 권장.
